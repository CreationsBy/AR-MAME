# Licensing and ROM ownership

MAME 2003-Plus is based on older MAME code with noncommercial licensing terms and components under additional licenses. It is not the same licensing baseline as current MAME. Review the exact pinned upstream source and every bundled dependency before distributing binaries or introducing commercial use.

Upstream: https://github.com/libretro/mame2003-plus-libretro/tree/0aaf055d11a5e144598711de626f9e0e558f49d5

The build retains the full upstream repository in its build workspace and copies top-level license/copying files into app resources. Redistributors must preserve all required notices and provide corresponding source, modifications, and any required dependency license texts; copying the few top-level files alone is not a complete distribution compliance process.

The original frontend source in this repository has not been assigned a separate permissive license. Do not infer permission to commercially redistribute it or the combined binary. Choose and document an appropriate frontend license before external distribution.

No commercial ROMs, BIOS images, CHDs, decrypted assets, or proprietary 3dSen code/profiles are included. Users supply files they are entitled to use. ROM copyright and emulator licensing are separate matters.
